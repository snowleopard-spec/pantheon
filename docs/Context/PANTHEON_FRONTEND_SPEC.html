Design spec — not part of the page

This file is a working mockup + spec for a redesign of scripts/bucket_returns.py's rendered report. Production is untouched; adopt by porting the tokens and layout into the script's HTML template. Bucket-level numbers above are real (2026-07-28 render); constituent returns are illustrative.

Concept

A carved stone ledger. "Pantheon" taken literally: warm basalt ground, ivory ink, Roman inscriptional capitals for the title, and the returns table treated as a frieze — the diverging 1Y bar is carved relief, not decoration. Built phone-first because the real usage is a home-screen glance after US close.

Tokens

basalt #16130F page tablet #1F1B15 surface incise #2E281F rules ivory #E9E1CF ink ash #9A8F7B muted bronze #C2A15F accent verdigris #57B3A3 positive ember #DE8266 negative
  • Type: Marcellus (display — title only, letterspaced caps) · IBM Plex Sans (UI) · IBM Plex Mono (every figure and ticker; tabular by design). Mockup loads Google Fonts; production should subset+inline (house style is self-contained HTML) or accept the declared system fallbacks.
  • Polarity pair validated (dataviz six-checks, dark surface): deutan ΔE 9.0 PASS, normal-vision 20.2, contrast ≥3:1. Verdigris replaces leaf-green specifically for red-green CVD distance; sign is additionally encoded by the +/− glyph and by bar direction, so color is never the only channel.
  • The frieze (signature): one shared-axis diverging bar per row, axis at 22% of track width (matches the data's negative range), linear scale clipped at +220% with a faded end for the two off-scale buckets — the printed number carries the truth, the bar carries rank-at-a-glance. Bars animate a single scale-in on load; prefers-reduced-motion disables it.
  • Bronze discipline: the accent appears only in the title, the axis diamond, open-state chevrons, and tickers. Everything else is ivory/ash.

Layout

  • <740px (the primary target): each bucket is a stacked row — name / big 1Y / frieze bar / compact 6M·3M·1M·1W mono line. No horizontal scrolling anywhere.
  • ≥740px: the same DOM becomes a grid table: name · frieze · 1Y · 6M · 3M · 1M · 1W · n, with a proper column header row.
  • Expansion: tap/click or Enter on a row reveals the constituent table (ticker, company, weight, score, mkt cap, 1Y). Production keeps the current sortable-column behaviour inside it.

Kept from production

  • The freshness line under the title (generation time + prices-through date).
  • Default sort by 1Y descending; per-window renormalisation and the $1 penny-stock floor are untouched — this is presentation only.
  • Print stylesheet inverts to light (see @media print tokens).
  • Fully self-contained output remains the goal for production.
